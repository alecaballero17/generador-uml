Trabajar sin conexión

Guía y prueba de audio

Di «Crea clase Usuario con atributos id y nombre». Para ampliar: «Agrega atributo edad de tipo entero a clase Usuario». Puedes revisar y corregir la transcripción antes de aplicarla.

El reconocimiento usa un modelo local; la interpretación admite estos comandos concretos. En móvil, el micrófono requiere HTTPS. El acceso localhost sirve para probar en esta computadora.
